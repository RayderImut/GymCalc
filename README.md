# GymCalc

GymCalc adalah website kalkulator fitness untuk menghitung BMI, Body Fat, BMR, dan TDEE.

## Fitur

- Mode terang dan gelap
- Tombol bahasa Indonesia dan English
- Warna cerah yang nyaman di mata
- Layout responsif
- Kalkulator BMI, Body Fat, BMR, dan TDEE

## Cara Menjalankan

Buka `index.html` langsung di browser atau jalankan lewat Live Server.
