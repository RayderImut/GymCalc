# GymCalc

GymCalc is a modern fitness calculator website that calculates:

- BMI
- Body Fat
- BMR
- TDEE

---

# Features

- Modern UI
- Responsive Design
- Real-time Calculator
- Modular JavaScript Architecture
- Fitness Metrics
- Professional Landing Page

---

# Technologies

- HTML5
- CSS3
- JavaScript

# How To Run

1. Open project folder in VS Code

2. Install extension:

```plaintext

```

3. Right click:

```plaintext
index.html
```

4. Click:

```plaintext
Open with Live Server
```
